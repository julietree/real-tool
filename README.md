# 리얼워크 교보재 재고관리 시스템

## 시작하기

### 1. 의존성 설치
```bash
npm install
```

### 2. DB 초기화 + 시드 데이터 생성
```bash
npm run setup
```

### 3. 개발 서버 실행
```bash
npm run dev
```

브라우저에서 http://localhost:3000 접속

---

## 주요 기능

| 기능 | 경로 |
|------|------|
| 재고 대시보드 | `/` |
| QR 코드 스캔 | `/qr` |
| 교보재 상세 (QR 결과) | `/material/[id]` |
| 발주 이력 | `/orders` |

## 스택

- **Next.js 14** (App Router)
- **Prisma + SQLite** (로컬 개발 / Supabase 마이그레이션 가능)
- **Tailwind CSS**
- **html5-qrcode** (카메라 QR 스캔)
